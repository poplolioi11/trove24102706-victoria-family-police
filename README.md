# 丈夫蠢狀（《東華新報》1900-02-21 第2版，澳洲國家圖書館） / Zhangfu chun zhuang [A Newspaper Account of a Husband's Sudden Distress]: Transcription Dataset

《東華新報》1900-02-21 刊載的〈丈夫蠢狀〉。報載維多利亞一名男子行為驟變，妻子返家確認，並向巡差求助尋人。文末記載未經確認的傳聞，原報未載明此人確切去向。

Zhangfu chun zhuang [A Newspaper Account of a Husband's Sudden Distress] appeared in Tung Wah News (1900-02-21). The report describes a man in Victoria whose behaviour changed suddenly. His wife checked the home and asked the police to help find him. The closing language records unverified rumours, leaving his whereabouts unresolved.

## V0.2.0

完整收錄第2版此篇原題與正文 5 個原欄，全文格式為 TXT、JSON 與 TEI XML。比對獨立原圖讀法後回圖裁定，採用 4 筆訂正，留存疑讀定位。

TXT, JSON and TEI XML cover the complete separately headed article, comprising the heading and 5 source columns on page 2. An independent image reading was compared with the first transcription. Source-image adjudication adopted 4 changes and retained unresolved readings.

## 方法與覆核 / Methods and review

由 AI 依固定館方影像逐欄讀字，保留原字、版面與疑讀。照錄原題、時代用字與原欄次。疑讀按欄記在 JSON。人類全文雙校、專家審定、同儕審查及準確率量測尚未進行。實際模型識別與使用量未知。此資料公開供比對與引用，處理程式及影像另存。

An AI assistant transcribed the fixed source images column by column, preserving source forms, layout and uncertain readings. Headings, historical terminology and source column order are preserved. Uncertainties are recorded by column. Human proofreading, expert review, peer review and accuracy measurement are pending. The actual model identifiers and usage are unknown.
